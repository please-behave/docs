# Examples

Illustrative files for the [Please Behave documentation](https://please-behave.github.io/docs/).
They use generic placeholders and synthetic values only.

- [`adapters/`](adapters/): the dummy adapter and its profile, described in the
  [adapter guide](../src/adapters.md).
- [`my-app/`](my-app/): an illustrative macOS project setup.

`mise run test-rule-examples` validates the rules and runs the dummy adapter with the
pinned CLI, offline.
